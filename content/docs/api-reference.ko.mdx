이 페이지는 대시보드가 호출하는 Z.AI 엔드포인트를 설명합니다. 이 엔드포인트들은 **Z.AI가 공식
문서로 제공하지 않습니다**. 여기 적힌 내용은 모두 GLM Coding Plan 계정의 실제 응답에서 확인한
것입니다(마지막 확인: 2026-09-15). 각 내용의 근거를 담은 전체 메모는
[`docs/zai-api.md`](https://github.com/MaxRyabov/zai-coding-plan-dashboard/blob/main/docs/zai-api.md)(영문)에 있습니다.

## 인증

모든 요청은 Bearer 토큰을 붙인 `GET`입니다.

```bash
Authorization: Bearer YOUR_API_KEY
Accept-Language: en-US,en
```

<Callout type="warn">
API 키를 안전하게 보관하세요. 대시보드는 키를 자체 `/api/usage` 경로로만 보내며, Z.AI 호출은 서버에서 이루어집니다.
</Callout>

## 기본 URL

```
https://api.z.ai
```

## 응답 봉투

모든 엔드포인트는 데이터를 다음과 같이 감싸서 반환합니다.

```json
{ "code": 200, "msg": "Operation successful", "success": true, "data": { ... } }
```

<Callout type="error">
**거부된 키도 401이 아니라 HTTP 200을 반환합니다.** 실패 여부는 `"success": false`와 업무 코드 `code`로 알 수 있습니다. HTTP 상태만 확인하면 유효하지 않은 키가 사용 기록이 없는 계정처럼 보입니다.
</Callout>

| `code` | 발생 조건 | 대시보드 처리 |
|--------|-----------|---------------|
| `1000` | 형식은 맞지만 승인되지 않은 키 | 401 |
| `1001` | `Authorization` 헤더 없음 | 401 |
| `401` | 토큰을 해석할 수 없음 | 401 |
| `500` | 경로가 없음(`404 NOT_FOUND`) | 502 |

`msg` 텍스트는 `Accept-Language`와 관계없이 영어 또는 중국어로 옵니다. `code`로 판단하고 `msg`는 표시하지 마세요.

## 시간 매개변수

`startTime`과 `endTime`은 `YYYY-MM-DD HH:mm:ss` 형식의 문자열이며, 호출하는 위치와 관계없이
**베이징 시간**(`Asia/Shanghai`)으로 해석됩니다. 두 값은 반드시 함께 보내야 합니다.

## 두 가지 요금제

| | 토큰 요금제 | 크레딧 요금제 |
|---|---|---|
| 한도 유형 | `TOKENS_LIMIT` | `CREDIT_LIMIT` |
| 5시간 및 주간 한도 | 비율만 제공 | 비율과 절대 크레딧 |
| MCP 한도 | 별도의 월간 `TIME_LIMIT` | 없음(MCP도 같은 크레딧 사용) |

사용량, 도구, 활동 엔드포인트는 두 요금제에서 같은 형식을 반환합니다.

### 할당량 한도 조회

모든 한도의 현재 상태를 반환합니다. 매개변수는 없습니다.

```http
GET /api/monitor/usage/quota/limit
```

**토큰 요금제:**

```json
{
  "limits": [
    { "type": "TOKENS_LIMIT", "unit": 3, "number": 5, "percentage": 64, "nextResetTime": 1789472583274 },
    { "type": "TOKENS_LIMIT", "unit": 6, "number": 1, "percentage": 100, "nextResetTime": 1789470235980 },
    {
      "type": "TIME_LIMIT", "unit": 5, "number": 1, "percentage": 1,
      "usage": 4000, "currentValue": 15, "remaining": 3985, "nextResetTime": 1790593435997,
      "usageDetails": [{ "modelCode": "search-prime", "usage": 13 }, { "modelCode": "web-reader", "usage": 2 }]
    }
  ],
  "level": "max"
}
```

**크레딧 요금제:**

```json
{
  "limits": [
    {
      "type": "CREDIT_LIMIT", "unit": 3, "number": 5, "percentage": 11,
      "usage": 28000, "currentValue": 3219, "remaining": 24780, "nextResetTime": 1789482908408
    },
    {
      "type": "CREDIT_LIMIT", "unit": 6, "number": 1, "percentage": 2,
      "usage": 140000, "currentValue": 3219, "remaining": 136780, "nextResetTime": 1790062251984
    }
  ],
  "level": "max"
}
```

| 필드 | 의미 |
|------|------|
| `type` | `TOKENS_LIMIT`, `CREDIT_LIMIT`, `TIME_LIMIT`(MCP 호출 수) |
| `unit` | 기간 단위: `3` 시간, `6` 주, `5` 월 |
| `number` | 창당 단위 수: `unit: 3, number: 5`는 5시간 창 |
| `percentage` | 사용 비율(정수 %) |
| `currentValue` | 사용량(크레딧 또는 호출 수) |
| `usage` | **상한값**이며 사용량이 아닙니다(이름이 반대로 되어 있음) |
| `remaining` | 상한값에서 사용량을 뺀 값 |
| `nextResetTime` | 에포크 밀리초 |
| `level` | 요금제 등급: `lite`, `pro`, `max` |

<Callout type="info">
창은 초기화 시각이 아니라 `unit`으로 구분하세요. 주간 주기가 끝나갈 무렵에는 주간 한도가 5시간 한도보다 먼저 초기화될 수 있습니다. 2026년 9월 이전 응답에는 `unit`이 없었고, 그때 믿을 수 있는 신호는 배열 순서(5시간, 주간, MCP)뿐입니다.
</Callout>

</Tab>

### 모델 사용량 조회

지정한 기간의 시간별 토큰 수와 호출 수를 반환합니다.

```http
GET /api/monitor/usage/model-usage?startTime=2026-09-14 18:00:00&endTime=2026-09-15 18:59:59
```

**응답**은 열 기반이며, 같은 인덱스를 공유하는 병렬 배열로 구성됩니다.

```json
{
  "x_time": ["2026-09-15 17:00", "2026-09-15 18:00"],
  "modelCallCount": [97, 91],
  "tokensUsage": [11852025, 9583075],
  "totalUsage": { "totalModelCallCount": 188, "totalTokensUsage": 21435100 },
  "modelDataList": [
    { "modelName": "GLM-5.3", "sortOrder": 1, "tokensUsage": [11852025, 9581795], "totalTokens": 21433820 },
    { "modelName": "GLM-5.3-Flash", "sortOrder": 2, "tokensUsage": [0, 1280], "totalTokens": 1280 }
  ],
  "granularity": "hourly"
}
```

- `x_time`은 베이징 시간이며 형식은 `YYYY-MM-DD HH:mm`입니다(2026년 9월부터 초 단위가 없음).
- 사용 기록이 없는 시간도 포함해 기간 내 모든 시간이 반환됩니다.
- `totalUsage`는 기간 전체를 다루며 시계열 합계와 같습니다.
- 모델별 `totalTokens`는 요청한 시간 범위로 **제한되지 않습니다**. 대신 `modelDataList[].tokensUsage`를 합산하세요.

</Tab>
<Tab value="도구 사용량">

### 도구 사용량 조회

시간별 MCP 도구 호출 수를 반환합니다. 매개변수는 모델 사용량과 같습니다.

```http
GET /api/monitor/usage/tool-usage?startTime=...&endTime=...
```

```json
{
  "x_time": ["2026-09-15 14:00", "2026-09-15 15:00"],
  "networkSearchCount": [0, 1],
  "webReadMcpCount": [0, 0],
  "zreadMcpCount": [0, 0],
  "toolDataList": [
    { "toolCode": "search-prime", "toolNameI18n": "Web Search MCP", "usageCount": [0, 1], "totalUsageCount": 1 }
  ],
  "toolSummaryList": [
    { "toolCode": "search-prime", "toolName": "联网搜索 MCP", "toolNameI18n": "Web Search MCP", "totalUsageCount": 1, "sortOrder": 1 }
  ],
  "granularity": "hourly"
}
```

- `toolName`은 항상 중국어이며, 영어 이름은 `toolNameI18n`에 있습니다.
- 성공 및 실패 횟수는 더 이상 제공되지 않습니다.

</Tab>
<Tab value="활동">

### 활동 조회

일별 합계와 연속 사용 일수를 반환합니다. Z.AI 대시보드의 *Activity* 블록과 같은 데이터이며, 두 요금제 모두에서 동작합니다.

```http
GET /api/monitor/credit-usage/activity?startTime=2025-09-15 00:00:00&endTime=2026-09-15 23:59:59&type=1
```

`type=1`은 개인 보기입니다. Z.AI 대시보드는 365일 전부터 오늘까지를 하루 단위로 요청합니다.

```json
{
  "granularity": "DAY",
  "timezone": "Asia/Shanghai",
  "summary": {
    "totalTokens": 7861995903,
    "peakDailyTokens": 298081078,
    "peakDailyTokensDate": "2026-07-07",
    "totalUsageDurationMs": 1957677158,
    "currentStreakDays": 1,
    "longestStreakDays": 37
  },
  "series": [
    { "date": "2026-09-15", "totalCredits": "3219.1337", "totalTokens": 21435100, "mcpCalls": 0 }
  ]
}
```

- `series`에는 사용 기록이 없는 날도 포함해 하루에 항목 하나가 있습니다.
- 크레딧 금액은 10진수 **문자열**이며, 토큰 요금제에서는 항상 `"0.0000"`입니다.

</Tab>

## 대시보드 프록시: `POST /api/usage`

대시보드는 브라우저에서 Z.AI를 직접 호출하지 않습니다. 자체 경로가 키와 기간을 받아 위
엔드포인트들을 병렬로 호출하고, 정규화된 객체 하나를 반환합니다.

**요청 본문:**

```json
{
  "apiKey": "…",
  "startTime": "2026-09-14 18:00:00",
  "endTime": "2026-09-15 18:59:59",
  "extendedStartTime": "2026-09-08 18:00:00",
  "extendedEndTime": "2026-09-15 18:59:59"
}
```

응답에는 `modelUsage`, `toolUsage`, `quotaLimit`(`billing: "tokens" | "credits"`, `level`, 각 한도의
`kind` = `tokens`·`week`·`mcp` 포함), `extendedUsage`, `activity`, 그리고 Z.AI 호출별 결과를 담은
`upstream.status`가 들어 있습니다. 전체 명세는
[README](https://github.com/MaxRyabov/zai-coding-plan-dashboard/blob/main/README.md#api-reference)를 참고하세요.

## 속도 제한

Z.AI는 속도 제한을 공개하지 않으며, 지금까지 제한에 걸린 적도 없습니다. 대시보드는 새로고침할
때마다 계정당 5번 호출합니다(모델 사용량 2번, 도구 사용량, 할당량, 활동). Z.AI가 `429`로
응답하면 대시보드는 데이터 대신 속도 제한 오류를 표시합니다.

<Callout type="info">
사용 데이터는 약 10분 늦게 반영됩니다. Z.AI 대시보드에도 그렇게 안내되어 있습니다. 세션 직후의 작은 차이는 정상입니다.
</Callout>
